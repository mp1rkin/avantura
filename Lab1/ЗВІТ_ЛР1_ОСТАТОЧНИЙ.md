### A.1 Генерація вибірки 2 (3D нормальний розподіл)

```python
def generate_3d_clusters(K, N_k, sigma_range, random_seed=42):
    """
    Генерація випадкової 3D вибірки з нормальним розподілом
    """
    np.random.seed(random_seed)
    
    X = []
    y = []
    centers = []
    sigmas = []
    
    for k in range(K):
        # Випадковий центр
        center = np.random.uniform(-10, 10, 3)
        centers.append(center)
        
        # Випадкова дисперсія
        sigma = np.random.uniform(sigma_range[0], sigma_range[1])
        sigmas.append(sigma)
        
        # Генеруємо точки для кластера
        cluster_points = np.random.normal(loc=center, scale=sigma, size=(N_k, 3))
        X.append(cluster_points)
        y.extend([k] * N_k)
    
    X = np.vstack(X)
    y = np.array(y)
    
    return X, y, centers, sigmas
```

```python
def remove_outliers_iqr(df, column):
    Q1 = df[column].quantile(0.25)
    Q3 = df[column].quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    
    df_filtered = df[(df[column] >= lower_bound) & (df[column] <= upper_bound)]
    
    return df_filtered
```

  🎯 Что такое кластеризация?

  Представь, что у тебя куча фотографий животных вперемешку. Кластеризация — это когда компьютер сам раскладывает их на
  кучки: "собаки", "кошки", "птицы" — без того, чтобы ты ему заранее говорил, кто есть кто.

  K-means — это конкретный алгоритм, который:
  1. Выбирает случайные центры кластеров
  2. Относит каждую точку к ближайшему центру
  3. Пересчитывает центры
  4. Повторяет, пока все не устаканится

  Что это: 1200 точек на плоскости, разделенные на 4 группы

  Простыми словами:
  Представь лист бумаги. На нём нарисованы 4 облачка точек — одно в левом верхнем углу, одно в правом верхнем, одно
  внизу слева, одно справа. Все точки хорошо разделены, их легко отличить.

  Зачем: Показать идеальный случай — когда кластеры хорошо различимы.

  Пример (упрощенно):
  Группа A:  ●●●●        Группа B:        ●●●●
             ●●●●                         ●●●●

  Группа C:  ●●●●        Группа D:        ●●●●
             ●●●●                         ●●●●

  Вибірка 2: 3D случайная (со сферами)

  Что это: 1250 точек в трехмерном пространстве, 5 групп

  Простыми словами:
  Теперь не лист бумаги, а коробка (3D). В ней плавают 5 облачков точек — как 5 рыбьих стай в аквариуме. Каждая стая
  имеет свой центр и свою "плотность" (где-то рыбки ближе друг к другу, где-то дальше).

  Как генерировал:
  - Выбрал 5 случайных центров в пространстве
  - Для каждого центра выбрал случайную "плотность" (σ от 0.3 до 1.2)
  - Набросал вокруг каждого центра по 250 точек

  Зачем: Проверить k-means в трехмерном пространстве с разной плотностью кластеров.

  🔧 Что такое нормализация?

  Проблема: Признаки имеют разные масштабы.

  Например:
  - Возраст: 18-70 (маленькие числа)
  - Годовой доход: 15,000-100,000 (огромные числа!)

  Если не нормализовать, k-means будет считать, что доход важнее возраста в 1000 раз!

  Решение — StandardScaler:
  Превращает каждый признак так, чтобы:
  - Среднее = 0
  - Стандартное отклонение = 1

  Было:
  Age = 25 лет
  Income = $50,000

  Стало (примерно):
  Age_normalized = -0.5
  Income_normalized = -0.3

  Теперь все признаки на равных!
